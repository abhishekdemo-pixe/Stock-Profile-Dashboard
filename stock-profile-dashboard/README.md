# Stock Profile Dashboard

A responsive stock profile and watchlist dashboard built with React, Vite, Recharts, and Lucide icons. Designed as a beginner-friendly portfolio project.

> **Important:** This project uses illustrative sample values. It does not connect to a live stock-market API, and the displayed prices and company metrics are not real-time data. Do not use them for investment decisions.

## Features

- Responsive dashboard layout with desktop sidebar and mobile navigation
- Stock overview cards and company profile panel
- Interactive price chart with 1D, 1W, 1M, 3M, and 1Y range controls
- Search across sample stocks
- Add/remove stocks from a watchlist
- Export the current watchlist to CSV
- Responsive watchlist table
- Demo notices for placeholder navigation items

## Tech stack

- React 18
- Vite
- JavaScript (ES6+)
- HTML5 and CSS3
- Recharts
- Lucide React icons

## Run locally

Requirements: Node.js 18+ and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

To make a production build:

```bash
npm run build
npm run preview
```

## Add to GitHub

1. Create a **public** repository named `stock-profile-dashboard` at https://github.com/new.
2. In a terminal, open this project folder and run:

```bash
git init
git add .
git commit -m "Build stock profile dashboard"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/stock-profile-dashboard.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username. If you created a README on GitHub first, either create an empty repository or follow GitHub's instructions for merging the initial commit.
